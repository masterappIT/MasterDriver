# 第一版的微信內驗收操作清單

`docs/PLAN.md` 第九節規定：第一版要通過微信內驗收才算過關。本清單把那八項拆成照著做的步驟，並補上第一版後來加入的功能（接駁、一句話發單、客服）。

電腦瀏覽器通過不算數。每一項都要在手機的微信裡實際操作，然後在 WhatsApp 裡再做一次。

## 開始之前

| 準備 | 說明 |
|---|---|
| 正式網域已部署 | 用正式網域測，不要用 `*.run.app` 網址（內地很可能打不開） |
| 簡訊通道已設定並啟用 | 後台「簡訊通道」：+86 用國內帳號，+852／+853 用國際帳號；各發一則測試簡訊 |
| 開發模式登入已關閉 | 後台「登入配置」。開著的話收不到真的簡訊，驗收無效 |
| 兩個測試微信群 | 至少各有兩部手機在群裡 |
| 手機 | 內地 iPhone、內地 Android、香港 iPhone、香港 Android，各至少一部；內地手機用內地網路，不開 VPN |
| 三個角色 | 派單司機 A、接單司機 B、接單司機 C（同時搶單要兩個人）；另一部手機當乘客，不用登入 |

## 回報方式

每一項記「通過」或「不通過」。不通過時請記下：哪一部手機（機型、系統版本、微信版本）、內地還是香港網路、做到哪一步、畫面顯示什麼，最好附截圖或螢幕錄影。

## 一、派單與搶單（每部手機都要做）

| # | 操作 | 預期結果 |
|---|---|---|
| 1 | A 在微信裡打開網站，輸入手機號碼取得驗證碼 | 60 秒內收到簡訊（+852 和 +86 各測一次） |
| 2 | A 輸入驗證碼登入 | 進入首頁；+86 號碼預設簡體，+852 預設繁體 |
| 3 | A 完全關掉微信，重新打開，再打開網站 | 仍然是登入狀態，不用再輸入驗證碼 |
| 4 | A 按「發單」，在「一句話發單」貼上一則真實的群組派單文字，按「自動填入」 | 時間、起終點、座位、價格被填進表格；核對有沒有填錯 |
| 5 | A 補上乘客電話，按「發出」 | 進入單詳情，看到可複製的群文字 |
| 6 | A 按「複製，貼到微信群」，貼到兩個測試群 | 文字完整、換行正常、連結可以點 |
| 7 | B 在群裡點連結 | **3 秒內**看到搶單頁（用碼錶或螢幕錄影計時；內地和香港網路分開記） |
| 8 | B 按「立即搶單」；第一次會要求登入和填司機資料 | 填完後搶到，看到「已接單」 |
| 9 | C 在另一個群打開同一條連結 | 5 秒內顯示「已被接走」，不能再搶 |
| 10 | B 搶到後的頁面（2026-10-14 起不再有「複製『已接單』貼回群」，各群打開連結已顯示被接走） | 看到乘客一段與出單者的聯絡方式，沒有貼回群的步驟 |
| 11 | B 按「致電乘客」和「複製號碼」（要先到乘客電話的顯示時間，或 A 在發單時選「搶到即顯示」） | 撥號畫面跳出；號碼可以貼上 |

## 三之一、收款方式（2026-10-14 加入，不擋第一版過關）

| # | 操作 | 預期結果 |
|---|---|---|
| 16a | A 在「我的 → 收款方式」加一個微信收款碼、一個轉數快 | 兩個都列出，收款碼圖片看得到 |
| 16b | A 出單時打開「乘客確認頁顯示收款方式」，填乘客價，把確認訊息傳給乘客 | 乘客確認頁出現「付款給 A」、乘客價和兩個收款方式 |

| 16e | 行程完成後 A 打開單詳情 | 出現「乘客付款了嗎？」提醒；按「已收款」後提醒消失，乘客頁顯示「已確認收到你的付款」 |

## 五之一、通知與提示音（2026-10-14 加入，不擋第一版過關）

| # | 操作 | 預期結果 |
|---|---|---|
| 22a | A 在微信裡打開首頁，點一下畫面，停在首頁不動；B 搶 A 的一張單 | A 的畫面上方幾秒內滑出「你出的單有司機接了」，有提示音（Android 也會震動）；鈴鐺出現未讀數字 |
| 22b | A 點那條提示 | 進入那張單的訂單詳情；回到通知列表，那一則不再有「新」 |
| 22c | A 把微信切到背景或鎖屏，B 標記完成；一分鐘後 A 回到微信 | 切走時沒有通知（照實記錄）；回來後鈴鐺有新的未讀，通知列表有「行程已標記完成」 |
| 22d | A 在「我的 → 通知設定」關掉「我出的單」，再出一張單讓 B 搶 | 沒有提示，通知列表也沒有新的一則；打開開關後恢復 |
| 22e | 平台人員在後台回覆 B 的客服；乘客在 A 的名片頁送出預約 | B 收到「客服回覆了你」；A 收到「名片頁有新預約」，點開到預約詳情 |

記錄：每部手機是否聽到提示音、是否震動、從對方操作到提示出現大約幾秒。內地網路和香港網路分開記。

## 過關標準

- 第 1 到 16 項在四部手機的微信裡全部通過，並在 WhatsApp 裡通過第一、三部分：第一版過關。
- 第 17 到 24 項（含 22a 到 22e）不通過時記錄下來修正，不擋第一版過關，但要在試點開始前修好。
- 任何一項在內地手機不通過而在香港手機通過，要特別標明：這通常是網域或網路的問題，不是程式的問題。
